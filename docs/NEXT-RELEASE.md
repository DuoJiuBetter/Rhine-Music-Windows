# 大型歌单修复记录

此修复已纳入 0.2.0 Public Preview，当前下载入口见仓库 README。以下是原排查和验证记录。

## 大型网易云歌单

网易云歌单详情的固定 SDK 模块会请求最多 100,000 首内嵌歌曲资料；播放器只使用该响应中的完整 `trackIds`，歌曲资料另按每页 50 首读取。下一版在保留 SDK 端点和加密协议的前提下，将内嵌资料请求量缩至 10 首，并修正 `s: 0` 被 SDK 默认值覆盖的问题。此改动不编辑 `node_modules`，重新安装依赖或打包时仍然生效。

歌单详情响应的默认安全上限为 8 MiB，其他网易云响应仍为 2 MiB。确有需要时，可在启动程序前设置进程环境变量 `RHINE_NETEASE_PLAYLIST_RESPONSE_LIMIT_MIB` 为 2 至 16 之间的整数；不在范围内的值使用 8 MiB 默认值。超过上限时，界面会提示歌单列表超过读取上限，详细报错仍保留 `NETEASE_RESPONSE_TOO_LARGE`。提高上限会增加单次请求的内存开销，不会改变平台自身的歌曲权限。

验证使用合成的 943 首歌单，确认请求仅包含 10 条内嵌详情、`trackIds` 保留 943 项、第一页及最后一页均正常转换为可选歌曲。

2026-10-12 使用公开歌单 `2851221535` 进行真实接口对照：未修改的旧代码仍返回 `NETEASE_RESPONSE_TOO_LARGE`；修复后的歌单详情返回 HTTP 200、943 个 `trackIds`、10 条内嵌详情，响应体 189,884 字节（约 0.181 MiB）。随后从网易云实时获取第一页 50 首和最后一页 43 首歌曲资料，两页均全部返回，且均可转换为有效歌曲条目。此验证未读取私人账号，也未启动桌面界面或播放音频；登录后的抽屉显示、实际播放及其他更大歌单仍待新版实机验收。
