# 播放队列循环、插入及柱子歌名

基线：15eff25（ControlsColor1）。分支：fix/queue-loop-song-ruler。

- 队列模型行按队列长度循环映射深度坐标，最后一首到第一首选择最近的物理位置；不增加无限模型或重复队列条目。
- 队列柱子直接使用实际播放队列的歌曲顺序、唯一条目标识、曲目数及歌曲标题。原来通用刻度用专辑标题，造成下一首名称与歌曲不一致。现在与普通歌单共用歌曲柱组件，插入歌曲有独立柱子。
- 名称在柱子上方显示；鼠标触及即读取缓存、显示，不等待原来的 120 ms，离开后隐藏。移除柱子处重复的浏览器原生标题浮窗，取消回收柱子时自动跳焦点。
- “下一首播放”为插入：A、B、C 播放 B 时添加 X，成为 A、B、X、C。搜索面板点击播放才替换当前位置；搜索模型详情点击播放改为插入并播放，重复点击同一首切换暂停／继续。
- 插入后在队列视图点击下一首，模型和柱子跟随实际播放项。队列重建后再以唯一条目标识定位，避免引用旧索引。
- 原歌单分页刷新保留插入条目在邻接歌曲之间的位置，不因回到队首而清除。顺序播放、随机及单曲循环包含插入项；前后切换不跳过相邻插入项。手动插入条目上限为 100，以维持有界队列。
- 循环模式按钮移到右上角停止按钮右侧，歌词进度条处不再重复。单曲循环图标为圆弧双箭头与独立绘制的中心“1”。

按维护者要求不运行类型检查、测试、界面／GPU／账号／音频验证。仅打包前端资源，复用已有宿主，不进行原生重编译；runtimeChecked=false。
