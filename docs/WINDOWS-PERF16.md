## 歌单名称卡片与列表

点击总览中的歌单名称，毛玻璃小卡片以 460ms 基准时长拉伸、移动到现有列表位置，内容随后淡入。列表顶部返回箭头以 360ms 基准时长收回名称卡片。使用内层包装的 FLIP 变换，名称 / 列表切换时才读取旧、新矩形；三维投影锚点持续随模型移动，逐帧更新不重启动画。保持现有虚拟歌曲列表、透明无箭头滚动条和点击歌曲定位模型的行为。

快速展开 / 返回从当前视觉矩形接续；动画完成、离开总览或元素回收时撤销动画和 will-change。开、关过程最多保留一个形状和一个内容动画，异步歌曲行更新不重播内容动画。列表初始占位高度与实际标题 / 滚动区一致，避免网络返回导致整个卡片跳变。键盘展开后焦点进入列表，返回时恢复名称。暖昼 / 深夜复用现有颜色、毛玻璃和主题转换，窄屏保留视口避让。全局动效速度实时影响动画，“减少动态效果”直接提交最终状态。

## 波点音乐

登录平台增加波点音乐，使用波点音乐手机 App 扫码。登录后活动平台、搜索、账号创建 / 收藏 / 我喜欢歌单、三维歌单歌曲、封面、歌曲资料、行歌词和平台返回音源一起切换。各平台保持独立会话；不把 QQ 会话当成波点会话。波点登录信息保存为当前 Windows 用户 DPAPI 加密的 `bodian-session.dpapi`，令牌和设备标识仅在本地服务保存，不返回前端、不进入日志或发布包。退出、取消挑战、账号代数和串行落盘复用原有实现。

协议参考 [MoeclubM/PyBodian](https://github.com/MoeclubM/PyBodian/tree/ceb7e4f62b2ebd0248300d43fa422e2bf11ee00c) 的 MIT 实现；[许可原文](../third-party/PyBodian-LICENSE.txt) 随 runtime 分发。接口为第三方桌面协议适配，非官方 SDK；没有引入 AGPL 的 bodian-music-api / Folia 代码，没有使用本机客户端凭据提取、数据库或日志读取，也不导入用户手填令牌。

扫码使用 `/api/ucenter/login/qrCode`、`qrCodeStatus` 和 POST `users/login` 的 authType 10，确认身份与换取身份不一致时结束挑战；轮询至少间隔两秒，关闭和最小化沿用取消 / 暂停。恢复账号使用私有喜欢歌单操作核对会话，不以公开个人主页的可读性当作登录证明。账号被明确拒绝时清除对应旧会话，旧请求不能清除较新账号。

搜索每页 20 首，歌单歌曲每页 50 首。自建与收藏歌单分别推进，收藏混合列表过滤 sourceType 6 专辑，但分页依据过滤前的原始服务页；不可用歌曲保留空位，不移动歌曲索引。歌曲资料暂时失败时，已有搜索 / 歌单资料保留，歌词仍可单独读取。行歌词适配现有同步、高亮、滚动和点击跳转，不增加逐字歌词显示功能。

播放保留 GET JSON body 和对应签名，先读取实际权限；状态 3 仅接受返回的试听地址，状态 1 / 4 请求普通 MP3，其他状态不请求完整音源。地区限制、权限和无地址分别报错，不伪装完整歌曲。播放地址来自平台响应并经过 Kuwo CDN 域名检查，封面使用现有有界本机代理，图片与音源请求不携带账号凭据。搜索 / 元数据 / 歌单复用四槽调度、16 等待任务、6000 歌曲和 128 短时结果缓存；单次协议请求超时 15 秒，压缩与解压响应各限 8 MiB。

波点协议的地区、风控、内容权限和接口变化可能影响可用性。没有真实账号 / 平台调用，不能把代码接通等同于扫码、歌单和播放实测成功。具体需要用户在新包确认。
