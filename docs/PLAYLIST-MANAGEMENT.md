# 歌单整理体验版 · 2026-10-16

基于已保留的 Ripple3（c3268eb），独立分支 feat/playlist-management。没有推送或发布 GitHub，没有原生重编译。

## 操作

- 网络搜索结果的「＋ 添加到歌单」打开目标歌单选择，只列出该平台自己创建的歌单，可按名称筛选或新建。
- 「我的歌单」总览标题旁、歌单抽屉上方，以及歌单面板提供「整理歌单」。
- 整理窗口可查看收藏歌单；仅自己的歌单显示已适配的写入操作。
- 可多选并移除歌曲（每次最多 50 首），或删除整张普通歌单；两者均需应用内确认。
- 大歌单按 50 首获取、窗口最多 20 行、最多缓存 8 页；保留连续滚动，不把上千首歌曲同时创建为 DOM。
- 深色／浅色跟随主界面。键盘焦点限制在原生 dialog，输入文字或滚动不会触发背景切歌。关闭或换账号取消过期界面请求。

## 平台范围

| 操作 | 网易云 | QQ 音乐 | 波点 |
|---|---|---|---|
| 新建、删除普通歌单 | 已接入 | 已接入 | 未核实写入协议 |
| 修改名称 | 已接入 | 未核实参数，暂不显示 | 未核实 |
| 添加、批量移除歌曲 | 已接入 | 已接入 | 已接入；真实写入待验收 |
| 收藏他人的歌单 | 只读 | 只读 | 只读 |

不提供歌曲拖拽排序、封面上传、批量迁移或跨平台匹配。“我喜欢的音乐”允许增删歌曲，禁止改名、删除整个歌单。

“已接入”表示代码和合成验证完成，不等同于当前平台已对真实账号写入验收。

## 核对来源

公开网页调研使用全新、未登录的临时浏览器，没有读用户浏览器凭据或修改真实歌单。

- [网易云公开歌单页面](https://music.163.com/playlist?id=2851221535)：列表、收藏操作及未登录边界。登录后的编辑交互无法在未登录状态完整验收。
- [QQ 官方公开歌单页面](https://y.qq.com/n/ryqq/playlist/3222752131)：歌曲行展示播放、添加到歌单、分享。当前公开网页加载的 common.chunk.ad5e47b12e2ca2168529.js 中，添加流程包含目标歌单选择和新建，写入使用 music.musicasset.PlaylistBaseWrite 的 AddPlaylist / DelPlaylist，以及 PlaylistDetailWrite 的 AddSonglist / DelSonglist，歌曲传 numeric songId 和 songType。仅参考交互、协议事实，没有复制网页代码或资源。
- 网易云复用锁定的 NeteaseCloudMusicApi 4.32.0 的 playlist_create、playlist_name_update、playlist_delete。Together1 修正曲目增删：原 playlist_track_add/delete 实际处理视频，改为 playlist_tracks 使用的 /api/playlist/manipulate/tracks 歌曲协议；保留负载格式，不复制 SDK 的自动重试行为。名称使用独立更新接口，不手工拼接 playlist_update 的 JSON。
- [PyBodian](https://github.com/MoeclubM/PyBodian) 的 bodian_toolkit.py 核实 POST /api/service/playlist/music 与 /api/service/playlist/music/delete、签名及 playListId/musicIdList 参数。仅开放当前账号自己的 source=5 歌单，收藏歌单只读；新建、改名、删除整张歌单未核实。已完成合成验证，未修改真实波点歌单。

## 正确性与边界

服务端校验账号版本、自己创建的歌单、歌曲标识和批量上限，网易云保存前重新核对平台返回的创建者。请求队列等待期间也核对账号，拒绝过期账号写入。平台凭据仍只留在本机服务端，沿用 Host／Origin／JSON 请求边界。

每个平台同时最多一项写入。写入不自动重试：连接中断不能证明平台未保存。保存成功后重载歌单及模型视图；结果无法确认时提示先刷新核对。写入前后使读缓存失效，版本隔离阻止旧读取重新填充旧缓存。

为避免 SDK 默认 n=100000 带来全量嵌入曲目详情，playlistDetail 的请求适配将 n 限制为 120，s 用 nullish 规则保留 0，trackIds 仍由平台返回完整列表。未修改 node_modules。

## 验证

新增服务端验证涵盖完整写入链路、只读／未知／系统歌单、非法参数、重复添加、账号切换、并发写入、失败不重试、QQ numeric 身份、未核实平台能力、HTTP 边界。浏览器使用合成账号、1200 首歌单检查选择、创建、改名、移除、删除、确认取消、深浅主题、虚拟列表、搜索添加不触发播放、异常恢复和关闭取消。

相关已有歌单／NetEase／QQ／波点测试一起运行。原有波点试听用例在未建立账号 scope 前写入假缓存，修改前代码同样失败；只调整该测试准备顺序，不改播放逻辑。

未验证真实账号的云端写入、平台风控和包装后的原生窗口；没有使用维护者账号执行写操作。上一版 Ripple3 目录和提交完整保留。
