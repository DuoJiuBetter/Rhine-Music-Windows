# 0.2.0 Public Preview · 2026-10-20

## 下载

Windows 10/11 x64 用户下载 Rhine-Music-Windows-0.2.0-public-preview-x64-Setup.exe，退出旧程序后安装。Source code 为源码，不是安装包。旧版预览保留，不覆盖或删除旧 Release。

## 更新

- 默认开启的模型循环开关；关闭后歌单、曲目、播放队列和本地专辑按实际数量展示，首尾停止浏览。
- 修正歌单元数据分页时隐藏已知位置模型的问题，以及追加队列后的列映射与空白缝隙。
- 大型网易云歌单读取不再下载所有内嵌详情，曲目资料分批读取；限制响应体大小并提供错误说明。
- 临时播放队列、插入下一首、搜索播放、队列模型行、队列选择栏、音量与重复模式图标。
- 歌单整理入口、歌词滑动与定位、歌词区域设置、音浪及颜色、自定义快捷键与帧数上限。
- 连续模型切换的动画和有界资源调度调整、封面准备 Worker、缓存复用与上传合并；性能因设备而异，不承诺固定帧率。
- Unicode 中文安装向导，固定 UTF-8 输入与带 BOM 说明文字；当前用户安装，卸载保留个人数据。
