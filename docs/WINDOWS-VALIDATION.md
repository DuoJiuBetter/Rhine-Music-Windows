## 性能测量

测试机：Intel i5-13400F、NVIDIA RTX 4070 SUPER。WebView2 154.0.4258.62 / ANGLE Direct3D 11。96 张合成专辑，三张上游抽象演示封面。性能记录位于本地 artifacts/benchmark/report.json，截图位于同目录。

```powershell
$env:RHINE_CDP = 'http://127.0.0.1:9227'
npm run benchmark:windows
node scripts/benchmark-pipeline.mjs
```

专用测试启动环境设置 WEBVIEW2_ADDITIONAL_BROWSER_ARGUMENTS=--remote-debugging-port=9227，并使用独立 WEBVIEW2_USER_DATA_FOLDER 和 RHINE_DESKTOP_DATA_DIR。普通可携带包不会开启 CDP。测试在同一个真实桌面 WebView 内通过 `render=reference` 和 `render=optimized` 对照；reference 关闭新增共享深度/实例缓冲/帧调度优化，其他前端及资源相同。

记录实际 drawing buffer 尺寸、DPR、GPU 型号、画质参数、帧间隔、CPU 提交时间与异步 GPU 时间。CPU 提交耗时不等于 GPU 耗时。不同画布尺寸、软件渲染或测试工具引发的窗口变化不能作为公平 FPS 对照。当前环境窗口帧间隔曾稳定在约 31 ms，必须继续排查显示/运行环境与实际渲染瓶颈，不把它包装成目标已达成。

最终对照为两组均验证 1920×1080 drawing buffer。为避免 WebView2 恢复系统 150% DPI 而重新放大画布，测试显式将 pixelRatio 上限设为 1；默认产品仍使用上游“原始”画质的 1.5 上限。两组的灯光、透射、阴影、AO、景深参数一致。

这轮改动主要减少 CPU 提交和静置绘制次数，尚未明显提高交互帧率。静置节流后的 GPU 单帧耗时反而更高，可能受 GPU 频率/供电及运行节奏影响，不能将这些不同帧调度条件的计时当作同负载速度比较。以上数据为单机单轮开发测量，没有重复抽样置信区间。

暖昼详情、深夜详情、总览及专辑架已经截图检查。逐像素描述性比较的 RGB 平均绝对差值约 0.095–1.007 / 255，包含呼吸动画时间差、SSAO 随机核及 FPS 文字差异；此数据不证明完全相同，也不替代真实曲库和显卡上的视觉验收。

Windows 自动化与完整上游回归均通过；实际可携带包通过内置解码器扫描/解码、全屏、最大化/还原、详情 Escape 不误退出全屏、主题/总览、最小化音频继续、绘制暂停及单实例恢复检查。真实目录选择对话框尚待人工验证。APE 实际样本及 macOS 专属测试明确跳过。
