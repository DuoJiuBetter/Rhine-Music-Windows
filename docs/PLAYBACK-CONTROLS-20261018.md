# 列表按钮与单曲循环 · 2026-10-18

## 列表操作

网络搜索结果和「我的歌单」总览抽屉的每一首歌曲，在同一行显示播放、下一首播放、添加到歌单三个独立图标按钮，边框、悬停和键盘焦点跟随深浅主题。下一首和添加不再放在歌曲行下面作为文字链接。名称仍可点击定位／播放，来源链接保留。

抽屉的名称保持原有定位模型行为，独立播放按钮定位后播放，正在播放的同一首可暂停／恢复。下一首按钮只修改临时优先队列，添加按钮打开现有的当前平台歌单选择窗口，二者均不误触播放或收起抽屉。不读取未加载的整库，不增加三维渲染通道。空缺／不可用曲目禁用操作。

## 播放模式

进度条上方的原播放模式按钮按「顺序播放 → 随机播放 → 单曲循环 → 顺序播放」切换，单曲图标为循环箭头内的 1，选择继续保存在现有偏好中。

- 单曲循环的自然结束从零开始当前歌曲，不通过分页歌单导航读取下一首。
- 手动上一首／下一首仍按顺序导航；上一首保留原有「播放超过 3 秒先回到开头」行为。
- 用户明确添加的「下一首播放」优先于单曲循环；该曲目消费后继续以单曲模式循环当前歌曲。
- 切换模式保留暂停状态和当前进度，不主动恢复播放。
- 普通网页音频、浏览器无缝路线和原生输出适配均处理自动／手动的差别。浏览器无缝预备同一首；原生输出使用已有 boundarySerial 识别同 ID 接续，避免漏掉下一次预备，不用时间回退猜测。

## 验证

174 项播放器／接口／平台回归通过，新增测试覆盖三种过渡模式的单曲续播、下一首优先、手动导航、暂停进度、浏览器无缝精确边界、原生同 ID 接续。原生输出为合成桥接测试，未宣称真实 CoreAudio 设备验收。

浏览器合成界面验证搜索和抽屉三个按钮同排、有边框、各自回调独立、禁用曲目、焦点恢复、播放状态、深浅主题及 393 px 窗口。网络搜索、歌词滑动／单曲图标、总览及一起听界面回归。测试不访问真实账号，不播放真实音频或启动三维场景；不运行 GPU 基准或原生重编译。
