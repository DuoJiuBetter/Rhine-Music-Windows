# 随源视图显示的播放列表行

本次调整以当前播放列表为准，而不是用整个搜索结果替换正在播放的来源。

- 当前 A → B → C → D，正在播放 B，添加下一首 X：列表为 A → B → X → C → D，当前 B 和播放进度不变。
- 同时在搜索列表播放 Y：替换当前槽位 B，列表为 A → Y → X → C → D，立即播放 Y；原歌单仍是 A → B → C → D。
- 搜索替换保留原来源的分页游标，因此插播后从原 B 的后继 C 继续；后台分页刷新不会把已替换的 B 再加入。替换后的 Y 参与当前列表循环；单曲循环会循环 Y，临时下一首结束后也回到 Y。

添加下一首或搜索播放后，现有三维阵列旁增加一行“播放列表”。它采用当前会话列表的条目顺序，保持重复插入歌曲的独立条目 ID；只显示真实条目，不循环复制队列模型，也不使用占位歌曲填充。移除、排序、替换或续载后同步更新。原有来源模型保留，不切换为独立队列场景。

这些播放操作不主动选中队列模型、不重播模型进入动画、不重置浏览/详情相机。只有用户点击播放列表按钮，才定位该行当前歌曲；后续自动播放不抢走用户正在浏览的模型。原有返回浏览、查看来源及列表编辑仍保留。我的歌单总览和整体展示中移除队列行，返回近景后按当前列表恢复。

顶部搜索、我的歌单、设置、播放列表均只显示图标，不显示中文标签或悬停 title；保留中文 aria-label 供辅助技术识别。设置使用齿轮，我的歌单使用唱片加右下三条横线。登录入口保持原样。

沿用原显示池、材质、封面缓存和阴影预算，队列更新采用保留姿态的 refreshLibrary 路径。普通播放尚未激活队列时不进行模型列表重建。队列仍为会话数据，不跨重启保存；大歌单仍按需续载，模型行代表当前已载入的播放列表。
