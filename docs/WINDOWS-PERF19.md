## 在线恢复

此前自动下一首会请求新的平台地址，任一次音源请求或媒体加载失败就进入错误状态，必须手动点播放重新请求。现在网易云 / QQ / 波点的浏览器在线播放在同一次播放意图中最多自动重试三次（初次加重试最多四次），等待 600 / 1400 / 2800ms；准备请求与媒体加载共享预算，成功恢复后也不无限重置预算。自动下一首和手动播放共用处理。

临时网络失败、HTTP 408 / 425 / 429 / 5xx 会重试；媒体网络错误与失效 URL 可重新取得地址并创建新元素。明确 HTTP 401 / 403 / 404、无效请求、空地址、浏览器手势拒绝和解码错误直接失败。保留试听 / 权限限制，不变更平台授予的内容。网易云登录业务码 301 传递为 401，上游 HTTP 4xx 保留状态；未知平台业务错误仍按既有错误处理，不能据此断言账号已失效。

重试保持歌曲和播放时间，在读取元数据后恢复位置；等待中拖动进度仍有效。错误事件与 play() 拒绝同时出现时，先更新操作代次，再释放旧音频，仅调度一轮重试。暂停 / 停止 / 选歌 / 切换账号 / 输出方式 / 销毁会取消当前等待和旧请求；已暂停元素后来报错也不会自动重新播放。新一次显式播放与下一首有新的预算。重试期间保持 loading，用尽次数才显示最终失败，不自动跳过或更换成其他歌曲。

QQ 复用传输模块的网络错误不再一律标为“登录请求失败”，曲库 / 音源域名使用对应提示；真实登录端点继续使用登录提示。保留本地服务 Host / Origin 与媒体域名校验，重试不会读取或泄漏凭据。播放器音源接口、平台协议与本地音频主流程复用原实现。
