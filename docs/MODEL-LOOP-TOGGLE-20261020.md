# 模型循环开关

基线：971e4bc（QueueSeam1）。独立分支 feat/model-loop-toggle。

设置 → 画面显示设置 → 模型排列 → 模型循环。默认开启；未保存过此项的旧用户保持循环显示，关闭后的选择保存在原有偏好设置中。

关闭时，歌单列、歌曲、临时播放队列和本地专辑仅在原始坐标范围显示，不复制到循环位置。歌单外壳仍按已知曲目总数保留，元数据或封面未下载不影响外壳存在；空歌单不生成歌曲外壳。有限显示池仍随视角移动，不为大型歌单一次生成全部模型。

滚轮、按键和模型浏览按钮在首尾停止；歌单切换时深度限制在目标歌单范围。搜索结果和临时队列同样遵守有限浏览边界。总览标签和专辑刻度使用相同显示策略。切换开关时将当前选中项和相机一起映射回原始坐标，清理旧显示副本，保留当前歌曲和详情状态。

本开关只控制模型展示与浏览，不修改顺序播放、随机播放或单曲循环等音频行为。歌曲自动切换仍可定位到真实模型。

继续保留主题、减少动态效果、9×48 显示池、封面缓存与并发预算。按维护者要求，只构建前端并打包复用宿主的体验版；未运行类型检查、测试、播放器、GPU 或真实账号验证，runtimeChecked=false。
