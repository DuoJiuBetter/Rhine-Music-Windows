# 播放列表入口、悬停说明、全局快捷键与音浪颜色

基线 b3d01dd（WaveFix2），独立分支 feat/player-controls-customization。

- 点击播放列表只定位到播放列表模型行，不再创建左侧队列工具／列表窗。模型行与临时播放队列逻辑保留。
- 顶部图标和设置控件补充悬停文字说明，复用 aria-label 和设置项名称。
- 鼠标点击普通按钮不再留下按钮焦点；取消浏览／详情／总览／关闭面板后的自动焦点转移，去掉黄色焦点方框。文字输入、复制诊断等必要的编辑操作保留。
- 自定义播放快捷键在应用内的面板、按钮、滑块等非文字编辑界面可用，不再被最近一次点击的按钮或设置页阻断。正在打字、使用下拉菜单、录入新快捷键或操作颜色盘时，保留对应编辑操作，避免抢键。快捷键不会注册到 Windows 系统全局。
- 个性化 → 音浪 → 音浪颜色：可跟随主题或展开自定义颜色，圆盘调节色相／饱和度，竖条调节明暗，也可以输入 HEX。所有音浪样式／位置共用同一配色，保留透明渐变和外缘线，不改波动算法。
- 自定义颜色随设置保存；旧配置没有颜色时仍跟随原主题。无新增依赖或外部颜色服务。

按维护者本次要求，不运行类型检查、测试、界面检查、GPU 或真实账号验证。构建体验包仅进行前端资源打包，复用现有 Windows 宿主，不进行原生重编译。runtimeChecked=false。
