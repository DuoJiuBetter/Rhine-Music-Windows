# 在线音乐与平台登录

Rhine Music · Windows 支持登录网易云音乐、QQ 音乐和波点音乐账号。登录平台后，网络搜索使用该平台的曲库，“我的歌单”读取该账号在当前平台可访问的歌单。歌单总览中每一行对应一个歌单，行内的歌曲沿列排列；选择歌曲可定位到对应模型并打开播放详情。

登录由用户在对应音乐 App 中扫码或确认。不同平台使用独立的账号会话；切换当前平台时，搜索、个人歌单及歌曲播放来源会随之切换。程序只使用平台实际返回的搜索结果、歌单和音源，不提供会员、DRM 或付费内容解锁。能否播放完整歌曲或试听片段由平台、账号、地区、内容权限和接口状态决定，搜索结果不保证一定有可播放地址。

## 界面截图

### 登录后的歌单总览

总览视角展示账号可访问的歌单；每一行是一个歌单，歌曲按列排列。

![登录后的歌单总览](media/windows-preview/playlist-overview.png)

### 选择音乐平台账号

在账号面板选择网易云音乐、QQ 音乐或波点音乐，再按对应平台流程登录。

![音乐平台账号选择面板](media/windows-preview/account-login.png)

### 当前平台曲库搜索

网络搜索结果来自当前选中的平台。搜索面板会显示平台名称及平台提供的歌曲结果。

![当前登录平台的网络搜索](media/windows-preview/network-search.png)
