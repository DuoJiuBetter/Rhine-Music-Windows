景深的失配回退改为已模糊颜色，焦内像素保留完整清晰颜色。详情接近时，背景阵列封面的辅助清晰层平滑淡出，让底层完整玻璃和封面遵循场景景深；当前抽出歌曲的独立封面清晰层保留。回到阵列时反向恢复。渐变只修改辅助通道的透明绘制，主场景、透射和深度中的印刷面仍不透明，所有临时材质状态在成功和异常时恢复。

不新增渲染通道、分辨率或逐实例循环，不关闭完整玻璃或可见面积优化，也不扩大遮挡范围删掉背景模型。全部画质沿用同一规则；没有启用景深时仍尊重用户设置。实际背景效果与性能需实机确认。
