# 播放列表循环列空隙修正

基线：8bb1bc2（PlaylistShell1）。独立分支 fix/queue-shelf-seam。

加入播放列表后，循环列周期包含播放列表这一列。`isQueueShelfAlias` 能识别它的循环位置，但 `queueShelfFile` 原来只接受原始列坐标，其他循环位置返回 -1。因此这些位置虽然占了一列，却没有任何模型，形成一个模型宽度的空白。

修正后，播放列表的各个显示位置都映射到同一份队列记录，歌曲数量和顺序不变，不向实际播放队列重复添加歌曲。选中循环位置后继续切歌，沿最近的播放列表列移动，不跳回原始列。保留 9×48 显示池、可见性裁剪和封面预算；歌单总览仍按现有逻辑隐藏播放列表。

按维护者要求，不执行类型检查、测试、播放器运行、GPU 或账号验证。只打包前端并复用现有 Windows 宿主，runtimeChecked=false；本记录是源码修正说明，不代表实机验收。

回退目录：release/Rhine-Music-Windows-Preview-20261020-PlaylistShell1。
