# Rhine Music Windows · 0.2.0 Public Preview

## 安装和升级

下载 [Windows x64 安装 EXE](https://github.com/DuoJiuBetter/Rhine-Music-Windows/releases/download/v0.2.0-public-preview/Rhine-Music-Windows-0.2.0-public-preview-x64-Setup.exe)，退出旧版后双击安装。默认当前用户安装，保留账号、个人音乐和设置。安装器提供开始菜单／桌面快捷方式以及 Windows 设置卸载入口。GitHub 自动生成的 Source code 压缩包供开发者使用，不是可运行的软件。

本次应用内版本为 0.4.1-preview-model-loop-1-public。先前 Perf21 文档仅代表历史版本，不能用其验证记录代替本版验收。

## 音乐、歌单与队列

在设置添加本地音乐文件夹，或在顶部账号入口登录网易云、QQ、波点音乐。搜索使用当前平台曲库，“我的歌单”显示当前账号可访问的歌单。平台限制仍适用，不保证所有歌曲完整播放。

播放队列与原歌单独立。下一首播放会插入临时队列；搜索中直接播放会替换队列当前项。队列模型通过顶部播放列表按钮定位，查看我的歌单／整体展示时隐藏。顺序、随机和单曲循环控制音频播放。

搜索和歌单曲目行的播放、下一首播放、添加到歌单是并列无边框按钮。云端歌单整理会修改对应平台的数据，使用前确认目标账号和歌单。

## 模型循环

设置 → 画面显示设置 → 模型排列 → 模型循环，默认开启并保存选择。

关闭后，歌单、歌曲、队列和本地专辑仅显示实际数量，不重复填充；滚轮和模型导航按键到首尾停止。仍保留有限显示池和按需加载，不会为了大型歌单一次生成全部模型。音频循环模式独立于这个开关。

## 歌词和操作

详情页默认歌词列表，可切换歌曲资料；支持歌词滚动和点击定位。空格暂停／恢复；默认上下切换歌单、左右切换歌曲，双击左右快进／回退 15 秒，长按左右 2 倍速，具体按键可在个性化设置修改。可选择导航按键是否同时触发播放。

画面显示设置可调整最大化／全屏行为、画质和帧率限制；个性化中可调整歌词高度、音浪、主题和减少动态效果。音量在顶部播放器控制处调整。

## 公开包范围

公开包不含 FFmpeg／ffprobe，额外解码需要用户自行安装。未捆绑云信原生 SDK，因此暂不提供一起听；不将本地开发包中的未验收功能当作公开版承诺。登录、曲库、歌单及普通播放保留。
